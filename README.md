# DevConf 2026

A responsive developer conference landing page built with **HTML** and **CSS**. The project presents conference information, speakers, pricing plans, and registration-focused content in a clean and modern layout.

## Overview

DevConf 2026 is a conference website concept for a developer event. It includes a hero section, event navigation, speaker cards, pricing/registration plans, and responsive layouts for different screen sizes.

## Features

- Responsive navigation bar
- Hero section with conference tagline and background image
- Primary **Register Now** call-to-action
- Speakers section with speaker profile cards
- Secure Your Spot section with multiple pricing plans
- Responsive layout for desktop and mobile devices
- Clean typography and spacing using custom CSS
- Conference-focused content structure suitable for a landing page

## Technologies Used

- HTML5
- CSS3

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/nabildev-hub/devconf-2026
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for a better development experience.
